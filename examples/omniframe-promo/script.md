# OmniFrame Studio — Signal to Cinema

Original 30-second product promo for OmniFrame Studio.

## Rights and asset policy

The supplied YouTube reference was used only for high-level SaaS-ad pacing inspiration. Its video, frames, edit, voice, brand assets, and Digitalism's music are not used. This project uses original procedural visuals, original procedural audio, and OmniFrame-authored UI copy.

## Audio plan

The delivery uses `output/omniframe-promo-bed.wav`, a deterministic original stereo bed generated by `generate_audio.py`. No reference recording, downloaded song, or unlicensed voice is used. Captions are delivered separately in `captions.srt` and can be burned into a review export.
